# Midterms Chess Style Guide

**Target:** Vinyl-toy collectible consistency across all 2D tokens, 3D figurines, and lose/kill-cam cinematics.

## Desktop Piece Standard (the bar)

From the existing GLB models (e.g. Rand Paul rook hover-card):

- **Head:** Large, detailed, matches the in-game GLB sculpt exactly
- **Body:** Chess-role specific (rook tower, horse body, bishop miter, etc.)
- **Clothes:** Professional suit/outfit appropriate to the character
- **Base:** Gold-rim dark marble pedestal
- **Look:** Glossy vinyl-toy collectible

## Non-Negotiable

**FACE AND SCULPT MUST MATCH THE IN-GAME FIGURINE.**

- Portrait → GLB → cinematic: same head, same proportions, same likeness
- The desktop 3D piece is the canonical sculpt for that character
- Gags, outfits, and props may change for specific cinematics
- The face does not

## Cinematics (kill-cam, lose reels, capture-order beds)

- Vinyl toys move like vinyl toys (rigid, topple, no squash-stretch)
- Same head sculpt as the GLB
- Same professional outfit (unless a specific gag requires a costume change)
- Gold-rim dark marble base visible when appropriate
- Locked camera, readable beats
- No super-caricature / Pixar look — we already have a caricature style (the desktop pieces)

## 2D Mobile Tokens

- Large head, recognizable likeness matching the 3D figurine
- Chess-role body visible (tower, horse, etc.)
- Gold-rim dark marble base
- Professional outfit
- Rendered from the same visual language as the 3D models

---

**When in doubt:** match the desktop GLB for that character. The 3D figurine is the single source of truth for face, proportions, and base style.
